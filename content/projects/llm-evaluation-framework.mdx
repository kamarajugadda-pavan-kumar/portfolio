## Overview

Evaluating RAG systems in production is unsolved. Existing tools (RAGAS, TruLens) are useful but opinionated — they assume a specific RAG topology and make GPT-4 judge calls for every metric, making continuous evaluation expensive at scale.

This framework is designed for daily automated evaluation on a rolling query sample, with a Streamlit dashboard for tracking metric drift over time.

> **Note:** This project is actively in development. The retrieval metrics and golden dataset tooling are complete; the LLM judge and dashboard are in progress.

## Architecture

The framework has three layers:

1. **Data layer** — Golden dataset management (query, expected answer, relevant doc IDs)
2. **Metrics layer** — Automated metrics + optional LLM judge
3. **Reporting layer** — SQLite time-series storage + Streamlit dashboard

## Key Metrics Implemented

### Retrieval Metrics (no LLM required)

```python
def context_precision(retrieved_ids: list[str], relevant_ids: list[str]) -> float:
    """Fraction of retrieved docs that are actually relevant."""
    relevant_retrieved = len(set(retrieved_ids) & set(relevant_ids))
    return relevant_retrieved / len(retrieved_ids) if retrieved_ids else 0.0

def context_recall(retrieved_ids: list[str], relevant_ids: list[str]) -> float:
    """Fraction of relevant docs that were retrieved."""
    relevant_retrieved = len(set(retrieved_ids) & set(relevant_ids))
    return relevant_retrieved / len(relevant_ids) if relevant_ids else 0.0

def mrr(retrieved_ids: list[str], relevant_ids: set[str]) -> float:
    """Mean Reciprocal Rank."""
    for rank, doc_id in enumerate(retrieved_ids, start=1):
        if doc_id in relevant_ids:
            return 1.0 / rank
    return 0.0
```
