## Overview

Placeholder — full case study coming soon.

This pipeline fine-tunes open-source LLMs (LLaMA-3-8B, Mistral-7B) on domain-specific instruction datasets using QLoRA for memory efficiency, with automated evaluation on held-out benchmarks and GGUF export for local inference via Ollama.

## Quick Notes

- 4-bit quantization via bitsandbytes — fine-tunes 8B models on a single 24GB GPU
- Unsloth for 2× training speed with flash attention
- Custom data curation pipeline: web scraping → LLM-assisted annotation → deduplication
- Evaluation: MT-Bench style prompts + domain-specific test set
